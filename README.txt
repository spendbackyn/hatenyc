HATENYC PORTFOLIO — SELF HOSTING

Files:
- index.html
- style.css
- script.js
- assets/profile.png

Quick hosting:
1. Upload the entire folder to your web host.
2. Make sure index.html is in the public/root directory.
3. Open your domain.

The site is static, so it does not require Node.js, PHP, a database, or a build step.
The Discord buttons are configured with your Discord ID and request server.
